把APP安装到手机主画面教学
iPhone
  1. 请先用 Safari 打开这个网站，不要用 Chrome 内建浏览器。
  2. 点底部的分享按钮。
  3. 往下找到“添加到主屏幕”。
  4. 确认名称后，点右上角“添加”。
  5. 回到 iPhone 主屏幕后，就能像 App 一样直接打开。
如果你现在不是用 Safari，先把网址复制到 Safari 再做一次。iPhone 不会跳出自动安装窗口，这是 iOS 的限制。
Android
  1. 先用 Chrome 或 Edge 打开这个网站。
  2. 先点“把APP安装到手机主画面教学”，再按照这里的步骤操作。
  3. 如果没有跳出安装窗口，就打开浏览器右上角菜单。
  4. 点“安装应用程序”或“添加到主屏幕”。
  5. 确认后完成安装，之后就可以从桌面直接打开。
看到可以点的安装按钮时，代表这台 Android 设备支持直接安装。如果按钮是灰色，通常改用 Chrome 打开就会出现。
